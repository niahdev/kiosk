# 키오스크 상단 내비게이션 제거 설계

## 목적

키오스크 실사용자가 화면 상단의 `Kiosk` 및 `Insert` 링크를 통해 입력 화면으로 이동하지 못하게 한다.

## 변경 범위

- `kiosk.html`에서 두 링크를 포함한 상단 내비게이션 요소를 삭제한다.
- 해당 링크의 주소를 설정하기 위한 `setTopNavLinks()` 함수와 호출부를 삭제한다.
- 프로젝트 데이터 조회, 상세 화면, 입력 페이지 자체와 다른 파일은 변경하지 않는다.

## 검증

- `kiosk.html`에 `data-nav-route`, `setTopNavLinks`, `/insert` 내비게이션 링크가 남아 있지 않은지 정적 검사한다.
- Docker 앱 이미지를 다시 빌드한 뒤 `/kiosk`가 정상 표시되고 상단 이동 버튼이 없는지 확인한다.
